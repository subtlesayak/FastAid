# Support

FastAid is a prototype project. It is not an emergency service.

If you are in immediate danger, call the official emergency number for your location.

## Project Help

Use GitHub issues for:

- Build problems
- Android Maps or Places setup questions
- UI bugs
- Nearby category mismatches
- Backend pilot configuration
- Documentation gaps

Do not post:

- API keys
- Admin passwords
- Live incident details
- Personal medical information
- Private responder data
