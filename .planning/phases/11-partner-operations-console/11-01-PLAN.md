# Phase 11 Plan: Partner Operations Console

## Goal

Turn the existing dispatcher shell into an authenticated, accessible operations console for controlled-pilot administrators.

## Requirements

- **OPS-01**: Administrators can review responders and set pending, verified, rejected, or suspended status.
- **OPS-03**: Pilot operators can review active and recent incidents, including duplicate-review signals.

## Implementation

1. Add administrator sign-in and bearer-session handling without persisting credentials.
2. Load real incidents, responders, audit events, notification attempts, readiness, and country configuration.
3. Add responder verification and suspension actions with explicit confirmation and audit feedback.
4. Add incident filtering and duplicate-review cues without automatically merging emergency reports.
5. Preserve keyboard access, focus visibility, live status announcements, responsive layout, and reduced motion.

## Verification

- Unauthenticated users see only the sign-in state and public readiness summary.
- Non-admin sessions cannot access protected data or controls.
- Administrator actions update the backend and refresh responder and audit views.
- Possible duplicates are suggestions only and never alter incidents automatically.
- Backend tests and a browser accessibility/interaction pass succeed.
